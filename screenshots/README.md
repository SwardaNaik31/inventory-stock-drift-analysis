# Screenshots Directory

This directory is intended for local project screenshots.

### Strict Privacy Rule:
- Any screenshots capturing real business inventory values, vendor names, pricing, or internal dashboards must **never** be committed to Git or uploaded.
- All image files (`*.png`, `*.jpg`, `*.jpeg`) in this directory are excluded by `.gitignore`.
- Only use synthetic demonstration data if you ever need to capture a screenshot for public repository documentation.
